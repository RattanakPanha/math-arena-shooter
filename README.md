# Math Arena Shooter

A browser-based online multiplayer shooting game with:
- multiplayer arena combat
- rank and level progression
- multiple weapons with switching
- 3 randomized Grade 11 math questions per round
- online play over Socket.IO

## Features
- Play in the browser with a simple lobby system
- Switch weapons using keyboard keys 1-5 or on-screen buttons
- Use WASD to move, mouse to aim, click to shoot
- Answer 3 random Grade 11 math questions each round
- Earn score, rank up, and level up

## Run locally

1. Install dependencies:
   npm install
2. Start the server:
   npm start
3. Open the browser:
   http://localhost:3000

## Controls
- W, A, S, D: move
- Mouse: aim
- Left click: shoot
- 1-5: switch weapons

## Notes
This project is designed for browser multiplayer and can be hosted on any Node-compatible server.
